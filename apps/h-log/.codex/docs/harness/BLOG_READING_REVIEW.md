# 기술 초안 목록·본문 통합 검수

검수일: 2026-10-16. 대상: `blog-reading-polish / Step 1`. [문체·읽기 개선 계획](BLOG_EDITORIAL_READING_PLAN.md)의 마지막 로컬 검수다.

T1 Step 2의 **최종 문체 교정본 2개**와 당시 제목·요약·태그를 새 격리 DB에 넣어 확인했다. 사실 검토본과 최종 교정본을 구분했으며 이번에는 산문을 추가로 고치지 않았다. 초안 전체와 근거 대장·검증 스크립트·캡처는 Git/Docker에서 제외한 로컬 `private/`에 보관한다.

미리보기는 루프백 주소에서만 실행했다. 공개 조회 경로를 검증하기 위한 로컬 `published` fixture를 사용했으며 운영 DB 저장이나 실제 공개 발행은 하지 않았다. 표시된 날짜는 화면 검사용 값이다.

## 초안별 편집·화면 결과

| 초안 | 제목·요약·도입부와 문체 | 사실·범위 보존 | 화면 결과 |
| --- | --- | --- | --- |
| 최근 글 조회가 늦어져도 홈은 먼저 보여주기 | 조회 대기를 소개 영역과 분리한다는 질문이 제목부터 도입부까지 이어진다. 요약은 빈 결과와 조회 실패의 차이도 예고한다. 최종 교정본의 해요체와 구체적인 동작 설명을 유지했다. | 기존 6개 claim과 코드·숫자·URL을 보존했다. 현재 Home 컴포넌트와 Suspense 배치는 설명과 일치한다. 본문의 테스트 35개와 지연·실패 브라우저 결과는 과거 기록이며 이번 결과로 바꾸지 않았다. | 세 폭에서 목록·검색·태그·본문을 확인했다. 코드 복사, 비교 표와 출처를 읽을 수 있고 긴 제목이 잘리지 않는다. |
| Redis Pub/Sub을 쓰기 전에 정할 메시지 유실 기준 | 놓친 알림과 완료를 남겨야 하는 처리 요청의 차이가 제목·요약·첫 문단에 연결된다. 문서 설명, 작성자의 판단과 향후 검증 계획이 구분된다. | 기존 5개 claim과 새 메시지 조회로 한정한 `NOACK` 설명을 보존했다. 가정한 사례를 실제 장애·전환 경험으로 바꾸지 않았고 실행·성능 측정을 추가로 주장하지 않았다. | 세 폭에서 목록·검색·태그·본문을 확인했다. 긴 제목, 표·목록·inline code와 본문 가까이의 출처 링크를 확인했다. |

두 초안에는 검증된 대표 이미지나 본문 그림이 없어 텍스트만 표시한다. 모바일의 두 줄 요약은 일부 말줄임되지만 다루는 문제가 드러나고, 상세에서는 요약 전체를 읽을 수 있다. 그림을 채우기 위한 자산을 새로 만들지 않았다.

긴 영문 제목·코드·표·H3·인용문과 그림은 **별도의 합성 글 1개**로 확인했다. 목록 썸네일과 본문 그림의 입력→검증 표현, 대체 텍스트와 설명이 연결되며 실제 초안의 경험이나 결과로 사용하지 않았다. 이 가상 글이 두 초안과 각각 태그를 공유하도록 해 관련 글 이동도 확인했다. 실제 두 초안끼리 관련성이 있다고 주장한 것은 아니다.

## 검수 중 수정한 오류 재시도

DB 조회 실패 뒤 데이터가 복구돼도 `app/blog/error.tsx`의 `reset()`만으로는 새 서버 요청이 발생하지 않아 오류 화면에 머물렀다. 실제 브라우저 재현과 기존 discovery 테스트의 실패를 먼저 확인했다.

버튼을 현재 주소의 `window.location.reload()`로 바꾸고 사용하지 않는 props를 제거했다. 새 상태 관리나 의존성은 추가하지 않았다. 같은 검사로 GREEN을 확인했고, 개발 서버와 로컬 production mode 모두에서 1440/390/320px의 검색 조건이 있는 목록 및 상세 주소를 재검증했다. 새 문서 요청, 정상 결과 복구와 query/tag/page/hash 보존이 통과했다.

## 완료 범위와 남은 발행 준비

| Phase | 완료 범위 |
| --- | --- |
| T1 `blog-writing-quality` | 작성 가이드·비공개 초안, 기존 writer의 정적 문체 규칙, 수동 교정과 모의 작성 계약 검증 |
| T2 `blog-list-presentation` | 목록/검색 공통 행과 검증된 선택적 썸네일·실패 fallback |
| T3 `blog-reading-polish` | 본문 글자·폭·여백, 최종 초안의 통합 읽기 검수와 발견한 오류 재시도 수정 |

3개 phase / 7개 step의 로컬 범위는 완료했다. 다음 항목은 이번 검수의 미해결 인수 조건이 아니라 실제 발행·운영 및 기존 후속 phase에 남은 작업이다.

- 실제 모델의 생성 문체는 평가하지 않았다. 기존 모의 writer 결과와 수동 교정 결과를 실제 모델 품질로 보고하지 않는다.
- 공식 자료 확인 시각은 T1의 2026-10-15 기록을 유지했다. 이번 UI 검수로 freshness를 갱신하지 않았다. 실제 생성·발행 전에 근거·버전·수집 시점을 다시 확인하고 기존 claim/privacy/quality gate와 공개 절차를 따른다.
- Home 글의 운영 지연·가용성은 미측정이다. Redis 버전·클라이언트·재연결·중복 처리·보관 조건은 별도 실행 계획이며 벤치마크나 장애 경험이 아니다.
- 실제 이미지 적용, 수정 이력과 시리즈, [선택과 재검증 사례](../../../phases/editorial-trust-and-series/step2.md)는 별도다. H-Log 초안을 사례 후보로 재사용할 수 있지만 해당 phase는 pending이다.
- OCI·실제 provider·운영 DB·공개 발행·timer를 실행하지 않았다. Home/레이더와 Second Brain의 구현은 유지했다.

다음 기본 작업은 기존 공개 경험 트랙의 [`blog-discovery-and-home / Step 3: rss-and-work-evidence-links`](../../../phases/blog-discovery-and-home/step3.md)다.
